## Getting Started

SarcDBase is implemented in python. Before you can run this repository, make sure to install and set up:

- Git. `https://github.com/git-guides/install-git`
- Conda. `Install it through miniconda or anaconda  `
- Python

### Installation

Clone the SarcDBase repository from the Github Page and execute the following commands to generate a conda environment with all you need to run the tool

```
git clone https://github.com//ValeriaDifilippo/SarcDBase
cd SarcDBase
conda env create -f bin/config/environment.yml
conda activate SarcDBase
```
or dowload manually the repository from the Git up page and then

```
cd SarcDBase
conda env create -f bin/config/environment.yml
conda activate SarcDBase
```

Create inputs and results directories in the NAFuse main folder 
```
mkdir -p results
```

**Project folder structure**

The project is organized into the following main directories:

- _bin/_
This directory contains all the source codes and scripts used to run SarcDBase. In the _config/_ subdirectory you can find the file to set up your environment.

- _annotation_files/_
Contains the annotation files in `.txt` format for the analysis, such as WHO_annotation_list_(hg19 or hg38).txt. You can upload in this folder your own annotation file.

- _results/_
This directory contains subdirectorie for each case with results generated by running SarcDBase. If you wish in the /results folder you can create a folder of your project and save there the results related to it.

## Usage
**Running SarcDBase**

***Set up***
It creates a subfolder in the results/ directory for each case, named as the case that is reported in the the cohort *_cohort.txt list. It also create a *_case_information.txt file that report the information present the *_cohort.txt, for example, sex, age etc... You can add all the information that you want.

```
python set_up.py -file cases.txt -output output_directory
python script.py -file cases.txt -output output_directory -filter Case1 Case3 
```
The default for -filter is ALL, meaning that all the cases reported in the list are analyzed, otherwise you can specify the spefici names, and a folder and the *_case_information.txt will be created only for those.

*** VERY IMPORTANT!!! The files that have to be analyzed need to be saved with the same name as present in the list!! ***
